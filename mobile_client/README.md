# Redwood Retail Mobile Client

An interactive, visually appealing mobile retail application client that connects directly to **Google Cloud Firestore Enterprise Native** (database: `redwood`, collection: `retail`). The application allows customers to browse hardware catalog items, manage cart and logistics, submit satisfaction feedback, and place orders that generate the **exact same JSON schema** as [`generate_retail_dataset.py`](../generate_retail_dataset.py).

Every submitted order streams via **Cloud Dataflow** in real-time to Google BigQuery (`redwood_retail.retail_cdc`) and powers **BigQuery ML customer churn models**.

---

## 1. Key Features

- **Visually Stunning Mobile Experience**:
  - Realistic **Mobile Device Frame** (iPhone 16 Pro mockup) with notch, system clock, and status indicators.
  - Seamless toggle between **Device Frame Mode** (for desktop browser demonstration) and **Full-Screen Mobile/PWA Mode** (for direct mobile phone interaction).
  - High-tech Redwood brand aesthetic with sleek dark glassmorphism, category color-coding, and micro-interactions.
- **Two Dedicated IAM Principals**:
  - **`demo1` (`demo1-user@elevate-cyvisser.iam.gserviceaccount.com`)**: Enterprise VIP member with 25% automatic discount, high spend profile, and positive sentiment default.
  - **`demo2` (`demo2-user@elevate-cyvisser.iam.gserviceaccount.com`)**: Standard Loyalty member with 10% discount, moderate spend, and active complaint risk testing.
  - Toggle between `demo1` and `demo2` anytime from the app header to switch identities dynamically.
- **100% JSON Schema Parity**:
  - Matches all top-level keys, 9 nested subsections, and value types generated by `generate_retail_dataset.py`.
  - Implements the complete **4-Pillars BigQuery ML Feature Matrix**: Demographics, Transactional Metrics, App Engagement, and Customer Support Satisfaction.
  - Sets `"metadata.sourcePlatform": "CUSTOM_MOBILE_APP"` and `"customerFeedback.channel": "MOBILE_APP"`.
- **Live Firestore Connection & Telemetry**:
  - Connects to Firestore Native using Application Default Credentials (ADC) and IAM role `roles/datastore.user` (provisioned via Terraform).
  - Real-time Order Feed displaying live statuses (`PROCESSING`, `SHIPPED`, `DELIVERED`).
  - Integrated **JSON Inspector Modal** with side-by-side raw JSON viewer, one-click copy, and 4-pillar churn feature breakdown.

## 3. Quick Start

### Step 1: Launch the Application
Run the launcher script from the `firestore/redwood` directory:

```bash
./mobile_client/start_mobile_app.sh
```

This starts:
- **FastAPI Backend**: `http://localhost:8000` (API & Standalone SPA)
- **Vite Dev Server**: `http://localhost:5173` (Mobile App Hot-Reloading)
- **Interactive API Docs (Swagger)**: `http://localhost:8000/docs`

## 5. Demonstration Walkthrough

1. **Open Mobile App**: Open `http://localhost:5173` or `http://localhost:8000` in your browser.
2. **Switch Identity**: Toggle between `demo1` (Enterprise VIP) and `demo2` (Standard Loyalty) in the header.
3. **Add Items**: Browse the Catalog and add industrial optical sensors, edge gateways, or PLCs to your cart.
4. **Inspect JSON**: Open the Cart tab and tap **"Inspect Generated JSON Schema"** to view the live JSON document matching `generate_retail_dataset.py`.
5. **Place Order**: Tap **"Place Order as demo1"**. The document is saved directly into the live Firestore Native `retail` collection.
6. **Track Real-Time Status**: Switch to the **Orders** tab to verify the order immediately appears in the live Firestore feed.
7. **Test Churn Alert**: Switch to `demo2`, select a 1-star or 2-star rating, choose a complaint reason (e.g. `LATE_DELIVERY`), and place the order. Inspect the document to see `hasActiveComplaint: true` and negative sentiment scores logged for BigQuery ML.
